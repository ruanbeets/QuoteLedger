HOW IT WORKS
A comparison you can trace
  1. Add a PDF or paste quote text. Common packaging terms are suggested.
  2. Open each quote, inspect the original text and correct any field.
  3. Confirm transport and enter a sourced ZAR exchange rate for foreign currency.
  4. Mark reviewed. The lowest complete, reviewed landed cost is highlighted.
Landed total = normalized box price × max(requested quantity, MOQ) + transport. Foreign currency amounts are converted using the rate you enter. VAT and tooling are excluded unless included in the quoted price; note them as exceptions.
